# 🧮 Neumorphic Glass Calculator

A high-end, responsive calculator application built using a **Glassmorphism** UI aesthetic. This project was developed as a technical demonstration of modern frontend web development for a college presentation.

## ✨ Key Features
- **Modern UI/UX:** Frosted glass effect using CSS `backdrop-filter: blur`.
- **Responsive Design:** Optimized for Mobile, Tablet, and Desktop screens.
- **Precision Logic:** Handles decimal calculations, backspacing (DEL), and operation chaining.
- **Dynamic Display:** Shows the current input and the previous operation for better user context.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure and Google Fonts integration.
- **CSS3:** Custom variables, CSS Grid, Flexbox, and Neumorphic shadows.
- **JavaScript (ES6):** State-based arithmetic logic and DOM manipulation.

## 📁 Project Structure
- `index.html` - The core structure and external links.
- `style.css` - Visual styling and glassmorphism effects.
- `script.js` - Arithmetic engine and display controller.
- `README.md` - Project documentation and author details.
